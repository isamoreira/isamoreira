## ⭐ Projeto em destaque: Escolha Fácil

> **Um site que mostra em linguagem simples, com fonte para conferir, o que está em jogo no 2º turno de 2026, para quem ainda tem dúvida em quem votar.**

<p align="center"><img src="https://raw.githubusercontent.com/isamoreira/escolha-facil/main/assets/og.png" width="80%" alt="Escolha Fácil: perguntas simples com respostas que têm fonte" /></p>

| | |
|---|---|
| 🎯 **Problema** | Informação eleitoral costuma chegar longa, técnica ou sem fonte, e é difícil saber o que é verdade e o que é promessa. Também falta um jeito fácil de ver quanta gente deixou de votar perto de você. |
| 💡 **Solução** | 33 perguntas diretas ("Você quer…?"), em 9 temas, cada uma com um selo (*Já existe*, *Já começou* ou *Está no programa*) e a página da fonte. Cada pergunta vira um card pronto para o WhatsApp. Uma página por estado mostra a abstenção cidade por cidade, e um gerador monta pedidos prontos para criar peças com IA. |
| 📦 **Dados / Fontes** | Dados abertos e portal de resultados do TSE (1º turno de 2022 e 2026, por município) e o programa de governo oficial, citado com o número da página. |
| 🧰 **Tecnologias** | HTML, CSS e JavaScript puro (sem framework e sem build), Open Graph para a prévia no WhatsApp, Apache `.htaccess` e hospedagem na Hostinger. Acessibilidade com fonte Atkinson Hyperlegible, alto contraste, leitura em voz alta e VLibras. |
| 📈 **Resultado** | Site leve e acessível, que funciona até em celular simples: 33 páginas de pergunta com card próprio, 27 páginas de estado e nenhum cookie ou dado guardado de quem visita. |

🔗 [Ver repositório](https://github.com/isamoreira/escolha-facil) · 🌐 [Demo](https://escolhafacil.online)
